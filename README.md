# Tetris 84 — Web Edition

Static browser game for GitHub Pages. Upload `index.html` and the `assets/` folder to the repository root and enable GitHub Pages from `main` / `(root)`.

Includes English/Russian UI, illustrated bilingual Instructions with original controls and historical note, touch buttons, local game save, statistics, Settings with sound toggle, donation and credits with CK My Apps logo.

For gameplay: start New Game, choose a level 0–9, and play with the keyboard or touch controls. Progress and settings are stored locally in the same browser. When you leave gameplay, it pauses; use Load Game to resume a saved snapshot.

The score mechanics are those of the previous web tribute and are **not yet a faithful implementation of the original 1984 scoring system**. Sound effects are retro terminal tones; a looping music theme has not been added. This project is a tribute, not an official Tetris release.

## App icon (new)
The green-and-black pixel-art **Tetris 84** icon appears on the main menu and is used for the favicon, iOS Add to Home Screen, and installable-browser web-app manifest. Icon files are in `assets/`. No Nintendo branding is included.
